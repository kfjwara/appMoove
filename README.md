# appMoove

iPhone向けオフライン動画プレイヤー PWA。Brave Playlist のオフライン再生の代替。

**アプリ:** https://kfjwara.github.io/appMoove/

## 使い方

1. iPhone の Safari で上記URLを開く
2. 共有メニュー →「ホーム画面に追加」
3. ホーム画面の Moove を起動 →「＋ 動画・音声を取り込む」で mp4 / mp3 / m4a 等を選ぶ（「ファイル」アプリから選択可）
4. 以降は機内モードでも再生できる

URL 取り込み（実験）では画質の代わりに「音声のみ」を選ぶと mp3 で保存する。
URL 取り込みには中継役（CORS プロキシ）が必要。[`proxy/`](./proxy/README.md) の Cloudflare Worker を自分でデプロイし、
その URL を「詳細設定」の「CORSプロキシ」欄に入れる（未設定のまま使うと案内が出る）。

## 仕組み（Phase 1）

- 動画は OPFS（アプリ専用ストレージ）に Worker 経由でチャンク書き込み（大容量対応）
- メタデータ（タイトル・再生位置・尺）は IndexedDB
- Service Worker がアプリ本体をキャッシュしてオフライン起動
- 再生位置の自動保存・レジューム・連続再生（オン/オフ切替可）つき
- 音声アイテムは `<audio>` で再生（ロック中・バックグラウンドでも鳴り続けやすい）。一覧では 🎵/🎬 で区別
- 再生速度（0.75〜2倍、記憶）、スリープタイマー（15/30/60分）、ロック画面のシーク操作に対応

### 注意

- Safari のタブとホーム画面アプリはストレージが別。動画は**ホーム画面アプリ側で取り込む**こと
- 保存上限は端末の空き容量に依存（概ね空きの6割程度）。空きが逼迫すると OS に消される可能性はある
