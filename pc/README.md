# appMoove 用 動画ダウンロード(Windows パソコン用)

パソコンで動画(または音声)をダウンロードして iCloud Drive に保存し、
iPhone の「ファイル」アプリ経由で appMoove に取り込むための道具です。

```
パソコンでダウンロード → iCloud Drive の「appMoove」フォルダ → iPhone の「ファイル」アプリ → appMoove に取り込み
```

- 保存される形式は iPhone で確実に再生できるもの(動画は H.264 + AAC の mp4、音声のみは AAC の m4a)です。
- 管理者権限は不要です。パソコンの設定(PATH など)も変更しません。

> 自分で見るための保存にとどめ、著作権や各サイトの利用規約を守って使ってください。

---

## 1. 初回セットアップ(最初に 1 回だけ)

準備するもの: Windows 11 のパソコン、インターネット接続、iCloud for Windows(iCloud Drive をオン)

1. この `pc` フォルダの中の **`setup.bat`** をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
2. 黒い画面に説明が出るので、**Enter** キーを押します。
3. 必要な道具(yt-dlp と ffmpeg、合わせて約 200MB)が自動でダウンロードされます。数分待ちます。
4. 「セットアップが終わりました」と出たら Enter で閉じます。
5. デスクトップに **「appMoove ダウンロード」** というアイコンができていれば完了です。

`setup.bat` は何度実行しても大丈夫です(すでに入っている物はダウンロードし直しません)。
アイコンを消してしまったときも、もう一度実行すれば作り直されます。

---

## 2. 普段の使い方

1. ブラウザで保存したい動画を開き、アドレス欄の URL をコピーします(Ctrl + C)。
2. デスクトップの **「appMoove ダウンロード」** をダブルクリックします。
   - 最初に道具の更新確認が自動で行われます(数秒)。
3. 「URL:」と出たら、**右クリック**(または Ctrl + V)で URL を貼り付けて Enter。
4. 番号を選んで Enter:
   - **1** … 動画 720p(おすすめ。何も入れずに Enter でもこれになります)
   - **2** … 音声のみ(音楽・ラジオ・講義など)
   - **3** … 動画 1080p(きれいですがファイルが大きくなります)
5. 「完了」と出たら保存されています。
   - 続けて別の URL を貼り付ければ、何本でも続けてダウンロードできます。
6. 終わるときは、**何も入れずに Enter**。保存先のフォルダが開きます。

保存先は **iCloud Drive の中の「appMoove」フォルダ**(`iCloudDrive\appMoove`)です。
iCloud Drive が見つからないときは、画面に案内が出て、代わりに「ダウンロード」フォルダの中の「appMoove」に保存されます。

### メモ

- プレイリストの URL を貼っても、その中の **1 本だけ** が保存されます。
- iPhone で再生できない形式だった場合は、自動で変換してから保存します(このときは少し時間がかかります)。
- ファイル名は動画のタイトルになります(長すぎるタイトルは短く切り、Windows で使えない記号は置き換えます)。同じ名前があれば「(2)」などが付きます。

---

## 3. iPhone 側の手順

### 最初に 1 回だけ:「よく使う項目」に登録

1. iPhone の **「ファイル」** アプリを開きます。
2. 「ブラウズ」→「iCloud Drive」を開きます。
3. **「appMoove」** フォルダを **長押し** →「**よく使う項目**」(または「お気に入り」)をタップ。
   - これで次からは「ブラウズ」画面の上のほうからすぐ開けます。

### 取り込み

1. パソコンでダウンロードしたあと、少し待ちます(iCloud への同期に数十秒〜数分かかります)。
2. iPhone で **appMoove** を開き、**取り込みボタン** を押します。
3. ファイルを選ぶ画面で「よく使う項目」の **appMoove** フォルダを開き、取り込みたいファイルを選びます(**複数選択** もできます)。
4. 取り込みが終われば、appMoove の中にコピーされています。オフラインでも再生できます。

### 取り込んだあとは iCloud 側のファイルを消してよい

appMoove に取り込んだ動画は appMoove の中に保存されているので、
**iCloud Drive の appMoove フォルダのファイルは消して大丈夫** です(iPhone の「ファイル」アプリでもパソコンでも消せます)。

---

## 4. iCloud の容量に注意(無料は 5GB)

- iCloud の無料プランは **5GB** です。iPhone のバックアップや写真と共有です。
- 動画は 720p で **10 分あたり 50〜100MB** くらいになります(1080p はその 2〜3 倍)。
- いっぱいになると同期が止まり、iPhone に届かなくなります。**取り込み終わったファイルはこまめに消して** ください。
- appMoove フォルダの合計が 3GB を超えると、ダウンロード画面の最後に注意が表示されます。

## 5. うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「必要なツールが見つかりません」 | `setup.bat` をもう一度ダブルクリックしてください。 |
| 「YouTube 側の仕様変更の可能性があります」 | 一度画面を閉じて開き直してください(起動時に yt-dlp が自動で最新版になります)。それでもだめなら半日〜数日おいて試してください。 |
| 「非公開」「メンバー限定」「年齢制限」 | ログインが必要な動画は、この道具ではダウンロードできません。 |
| 「インターネットにつながらない」 | Wi-Fi などの接続を確認して、もう一度試してください。 |
| 「選んだ画質のファイルが見つかりませんでした」 | 別の番号(1 ⇔ 3)で試してください。 |
| Node.js が見つからないという注意が出る | YouTube のダウンロードには JavaScript の実行環境が必要です。[Node.js 公式サイト](https://nodejs.org/ja) から LTS 版をインストールしてください。 |
| iPhone の「ファイル」アプリに出てこない | パソコンの iCloud for Windows が起動していて、iCloud Drive がオンか確認してください。同期には少し時間がかかります。iPhone の「ファイル」アプリで画面を下に引っぱると更新されます。 |
| 保存先が「ダウンロード」フォルダになった | iCloud Drive のフォルダ(`C:\Users\<ユーザー名>\iCloudDrive`)が見つかりませんでした。iCloud for Windows で iCloud Drive をオンにしてください。それまでは、できたファイルを手で iCloud Drive に移しても大丈夫です。 |
| 黒い画面がすぐ閉じてしまう | `pc` フォルダの `setup.bat` をもう一度実行してから、デスクトップのアイコンを使ってください。 |
| ウイルス対策ソフトに止められた | yt-dlp / ffmpeg は公式配布元(GitHub)から取得し、公式のチェックサムで確認しています。ソフト側で許可してから `setup.bat` を再実行してください。 |

---

## 6. アンインストール(削除)

次の 2 つを消すだけです。

1. デスクトップの **「appMoove ダウンロード」** アイコン
2. **`%LOCALAPPDATA%\appMooveDL`** フォルダ
   - Windows キー + R を押して `%LOCALAPPDATA%` と入力して Enter → 開いたフォルダの中の `appMooveDL` を削除します。

iCloud Drive の appMoove フォルダ(保存した動画)は自動では消えません。いらなければ手で消してください。

## 参考(詳しい人向け)

| ファイル | 役割 |
|---|---|
| `setup.bat` / `setup.ps1` | `%LOCALAPPDATA%\appMooveDL\` に `download.bat` / `download.ps1` をコピーし、`bin\` に yt-dlp.exe と ffmpeg.exe / ffprobe.exe を取得、デスクトップにショートカットを作成 |
| `download.bat` / `download.ps1` | ダウンロード本体。起動時に `yt-dlp -U`、終了時に保存先を開く |

- 取得元: yt-dlp は <https://github.com/yt-dlp/yt-dlp/releases/latest>(`SHA2-256SUMS` で照合)、
  ffmpeg は <https://github.com/yt-dlp/FFmpeg-Builds/releases/tag/latest> の `ffmpeg-master-latest-win64-gpl.zip`(`checksums.sha256` で照合)。
- YouTube は JavaScript ランタイムが必要です(yt-dlp の既定で有効なのは Deno のみ)。Node.js があれば `--js-runtimes node:<node.exe のパス>` を付けて使います。
- 形式の選び方: `-f "bv*[vcodec^=avc1]+ba[acodec^=mp4a]/b[vcodec^=avc1][acodec^=mp4a]/bv*+ba/b" -S res:720`(1080p は `res:1080`)、音声は `-f "ba[acodec^=mp4a]/ba/b" -x --audio-format m4a`。
  ダウンロード後に ffprobe で確認し、H.264(yuv420p)/AAC でなければ ffmpeg で変換、最後に `-movflags +faststart` で書き出します。
- `.ps1` は **UTF-8(BOM 付き)**、`.bat` は **ASCII のみ** で保存しています(Windows PowerShell 5.1 / cmd で日本語が化けないように)。編集するときはこの形式を保ってください。
- 動作確認用オプション: `download.ps1 -SaveDir <フォルダ> -NoOpenFolder -SkipUpdate`、`setup.ps1 -Yes -NoPause`。
